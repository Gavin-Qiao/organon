# NeurIPS mandatory checklist and back-matter order

The official NeurIPS checklist guidance verified 2026-08-23 makes the checklist mandatory and desk-rejectable if absent. One PDF contains paper content, references, optional technical appendices, then the checklist; the checklist does not count toward the content-page limit. Each item is answered yes, no, or N/A with a justification or pointer where useful. The checklist must remain in the eventual final paper as well as the submission.
