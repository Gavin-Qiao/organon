# Cleveland McGill 1984 - graphical perception ranking

Ranks elementary perceptual tasks by judgment accuracy: position on a common scale first, then length, direction, angle, area, shading, color saturation last. editio-figures uses it as the chart-form tie-breaker: encode the claim's key comparison as position whenever possible.
