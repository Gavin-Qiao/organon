# LightMem separates foreground memory from offline consolidation

The ICLR 2026 LightMem paper combines lightweight filtering, topic consolidation, and offline sleep-time updates. Across its LongMemEval settings it reports accuracy gains up to 10.9 percent while reducing token use by up to 117 times, API calls by up to 159 times, and runtime by over 12 times. The design supports cheap foreground writes and deferred consolidation; the maxima should not be read as universal effects.
