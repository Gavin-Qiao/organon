# Ongaro & Ousterhout 2014 (Raft) - understandability as a goal (exemplar)

The consensus algorithm designed and evaluated for understandability. The exemplar of decomposition-as-proof: sections structured around how a reader rebuilds the system (leader election / log replication / safety), the invariant restated at each stage, and an evaluation (a user study) matched to the actual contribution. Grounds the exemplars reference (practice: structure around the reader's reconstruction, not the implementation history).
