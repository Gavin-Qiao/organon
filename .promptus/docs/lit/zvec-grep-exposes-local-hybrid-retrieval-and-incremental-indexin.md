# Zvec-grep exposes local hybrid retrieval and incremental indexing

The zvec-grep pipeline documentation describes structure-aware Markdown extraction, indexed lexical/vector routes, exact ripgrep, and incremental updates using stored model and file-selection settings. Package 0.2.1 exposes createZvecGrep with explicit root, home, modelCacheDir, CPU device, index and context methods. Its pinned local/potion-retrieval-32m model uses Model2Vec and runs on CPU. Promptus still needs unit identity, lifecycle, and provenance around file-oriented candidates. Capability descriptions and vendor benchmarks do not establish comparative performance for research memory.
