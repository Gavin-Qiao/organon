# IEEE author center - figure size, type, and resolution rules

IEEE journals (TPAMI included): single column 3.5in/88.9mm, full text 7.16in/182mm; figure type ~9-10pt at final size; raster >300dpi color/grayscale, >600dpi line art; vector preferred (PS/EPS/PDF), PNG/TIFF accepted. Cross-checked against IEEEtran.cls and a local compile - all three agree. Feeds tpami/venue.json and the editio-figcheck gate.
