# MemoryAgentBench evaluates four memory competencies

The ICLR 2026 MemoryAgentBench paper evaluates accurate retrieval, test-time learning, long-range understanding, and selective forgetting over incremental multi-turn interactions. Its evaluated long-context, RAG, and agentic-memory systems do not master all four competencies. For Promptus this is an evaluation taxonomy, not a request for more storage machinery.
