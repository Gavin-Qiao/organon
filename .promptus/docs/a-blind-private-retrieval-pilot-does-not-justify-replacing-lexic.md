# A blind private retrieval pilot does not justify replacing lexical search

## Conclusion

The frozen Psi/MoT pilot does not justify replacing Promptus lexical retrieval with zvec-grep. The CPU-friendly zvec-grep 0.2.1 plus Potion retrieval 32M route returned somewhat more useful context, but did not consistently improve exact evidence retrieval. This is an exploratory result for the tested stack and project copies, not a judgement of all zvec engines or embedding models.

## Evidence

Five requested gpt-5.6-luna agents at max reasoning worked in fresh contexts: one source-only question author per project, one methodology/scoring auditor, and one fresh route/rank-blind passage judge per project. Each project contributed 12 frozen questions: four conceptual, two exact, two historical, two multi-source, two unsupported-premise probes. Both author suites passed exact source-identity, lifecycle and quotation checks before retrieval. Frozen corpora contain Psi 6494 and MoT 6332 units. Two independently built zvec indexes per corpus completed with no failed/pending files; the top-five ordered results were identical for all 24 queries across builds. Private pools contain 181 question–passage pairs.

Across the 20 positive questions, lexical versus primary zvec: known-target Hit@5 18/20 versus 17/20; Hit@10 18/20 versus 18/20; mean reciprocal rank at 10: 0.725 versus 0.606; blind direct-evidence precision@5: 61% versus 59%; useful-evidence precision@5 including background: 90% versus 94%. Each precision denominator is 100 positions (20 questions times 5). By project, direct precision was Psi 66% versus 58%, MoT 56% versus 60%; useful precision Psi 90% versus 92%, MoT 90% versus 96%. The second vector build reproduced these top-five quality scores.

There are specific strengths and weaknesses. Historical questions recovered all author-labelled groups in the top five in 2/4 lexical versus 4/4 zvec cases. Multi-source questions recovered all labelled groups within ten in 3/4 lexical versus 1/4 zvec cases. Both routes missed two conceptual target labels within ten on MoT, while judges still found some alternative useful passages. Known-target coverage is therefore not exhaustive recall, and direct evidence for one part is not proof of complete multi-part answer coverage.

Four unsupported-premise probes were scored separately. Direct answer evidence may reject a premise; these counts do not certify the premise, prove universal absence or measure generated-answer hallucination. No answers were generated by the benchmark.

The exact quotation gate caught 10 initial transcription failures (4 Psi, 6 MoT). Original judge drafts were retained. Still-blind judges revised 25 quotation fields total; deterministic comparison verified zero changed grades and zero changed rationales. All final 181 ratings and positive quotations passed. This demonstrates transcription safeguards, not independent correctness of relevance judgments.

## Boundary and next decision

Keep lexical as the default. Zvec remains a plausible optional context-retrieval supplement, especially for historical chains, but a combined route was not tested and is not an adoption recommendation yet. A stronger next evaluation would use naturally occurring failed searches and end-to-end continuation tasks, with independent expert review where possible. The earlier CPU replay remains the source for source-verification and update costs; this pilot measures ranking, not complete service latency.

The comparison is between native routes, not isolated vector engines: lexical uses its native title/path/status features; zvec uses opaque projected filenames and requests up to 100 context entities, then deduplicates and filters canonical eligibility. Both use the same final scope rule, but their candidate-generation sets differ. Default lexical production behavior down-ranks inactive units; this evaluation explicitly excludes them for nonhistorical questions. Corpus/question/source hashes were frozen; package manifest and model bytes were checked, but the full native dependency closure and resolved agent model build were not certified.

Small source-conditioned question sets and one same-model-family judge per project are not human gold, inter-rater agreement, significance or scientific-truth validation. Private text, questions, rankings, labels, vectors and logs remain in temporary storage outside the repository, not durable archives. No live Psi/MoT/Probatio/Mensura store, installed plugin, production source, dependency installation, commit, push, tag or release was changed by this pilot. New benchmark code/documentation and Organon's own gated research records were added.
