# ReMemR1 preserves revisitable memory instead of forward overwrite

The ICLR 2026 ReMemR1 paper identifies information loss in forward-only memorize-while-reading systems that overwrite earlier state. Its callback-enhanced memory can revisit the full history and improves multi-hop long-context reasoning. Promptus should preserve immutable history and derive a current view rather than making an evolving summary the only authority.
