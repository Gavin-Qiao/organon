# GPT-6 guidance favors precise instructions and calibrated completion

The official GPT-6 Astra guide recommends auditing skill and AGENTS instructions because stronger instruction following makes conflicting guidance consequential. It identifies unnecessary clarification pauses and excessive testing on small coding changes, and recommends defining intended completion and tuning delegation explicitly. These are model-specific engineering recommendations, not measured Organon improvements. The overhaul should compare the old and revised instruction surfaces using controlled tasks while preserving source and artifact verification.
