# Nature formatting guide - caption grammar and the summary paragraph

Nature's author guidance: legends open with a brief title sentence then a panel-by-panel description, with error bars defined and exact n stated; statistical tests named in Methods. editio-figures' caption grammar follows it; the annotated summary-paragraph template backs editio-structure's abstract formula.
