# Leisch 2002 Sweave — the Sexpr inline computed value

Leisch F (2002), 'Sweave: Dynamic Generation of Statistical Reports Using Literate Data Analysis', Compstat 2002 Proceedings, 575-580, Physica-Verlag. Introduces \Sexpr{}: live-computed R values inlined into typeset LaTeX prose — the direct technical ancestor of editio's \editionum (which binds statically at --write instead of compile-time, keeping script-over-server). Verified via Crossref + Springer 2026-07; canonical title is Title Case.
