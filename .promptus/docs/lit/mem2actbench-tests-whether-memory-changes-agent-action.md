# Mem2ActBench tests whether memory changes agent action

The ACL 2026 Mem2ActBench paper tests whether recalled history changes tool selection and parameter grounding rather than merely supporting question answering. Its 400 tasks derive from 2,029 sessions; human review judged 91.3 percent strongly memory-dependent, and seven evaluated memory frameworks remained inadequate. Promptus should therefore measure action use separately from retrieval.
