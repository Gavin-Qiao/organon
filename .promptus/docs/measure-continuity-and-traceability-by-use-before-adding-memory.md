# Measure continuity and traceability by use before adding memory machinery

Recent top-venue memory work converges on a behavioral evaluation boundary: accurate retrieval, cross-session synthesis, temporal update and selective forgetting, abstention, and action use must be scored separately. Provenance work further distinguishes locating a citation from showing how evidence supports an inference. For Promptus, the smallest useful response is an isolated replay harness over immutable history, source and artifact traces, and explicit stale-state handling—not more required ontology. Foreground writes stay cheap, consolidation is deferred, and current views remain derived from revisitable Markdown history. The synthetic harness establishes only mechanism coverage; project effectiveness requires later sanitized case bundles or operator-approved immutable snapshots.
